# OTK.LiteUI

A lightweight, batched UI library for OpenTK, designed for responsive tooling, low rendering overhead, and straightforward integration.

OTK.LiteUI provides a collection of UI components, layouts, and rendering utilities for building interactive interfaces in OpenTK applications. It supports both programmatic UI construction and JSON-based UI definitions.

## Features

- **Batched rendering** – Efficiently renders UI components using instanced drawing.
- **UI components** – Buttons, labels, text fields, checkboxes, sliders, panels, and more.
- **Layouts** – Automatically arrange components within containers.
- **Input handling** – Mouse, keyboard, text input, and focus management.
- **Scrolling** – Scrollable containers and linked scrollbars.
- **JSON UI loading** – Build UI hierarchies from JSON definitions.
- **Customisation** – Configure textures, colours, fonts, and materials.

## Requirements

- .NET [8.0]
- OpenTK [4.9.4]
- OpenGL [4.1]
